# Portafolio de Francisco Puñal

Página web personal realizada para la asignatura de Competencias de 2.º de Desarrollo de Aplicaciones Web.

## Tecnologías

- HTML5 para la estructura y el contenido.
- CSS3 para los estilos, con Flexbox y Grid para la distribución.
- Sin frameworks ni librerías externas.

## Contenido previsto

- Presentación personal, imagen y enlaces de contacto.
- Descarga del currículum en PDF.
- Proyectos con previsualizaciones y enlaces: ListApp, Hundir la Flota y CV en HTML y CSS.
- Experiencia laboral y formación.
- Gustos personales.

## Estructura

- `index.html`: página principal.
- `style.css`: hoja de estilos.
- `assets/`: recursos de la web, como imágenes y currículum.
- `fuentes/`: enunciado y wireframe de referencia.

## Cómo verlo

Abrir `index.html` en un navegador. Los recursos deben conservarse dentro de sus carpetas para que los enlaces funcionen.

## Estado

En desarrollo. Incluye la presentación, la foto, los enlaces de contacto, la descarga del CV y los títulos, descripciones y enlaces de los proyectos. Cuenta con estilos básicos y una distribución adaptada a pantallas pequeñas. Las capturas y las demás secciones están pendientes.
